# Periodic Checks & Maintenance (Heartbeat)

## Daily & Task Operations
- [ ] **Daily Agenda**: Review today's pending tasks and deadlines from `memory/YYYY-MM-DD.md` and active project trackers.
- [ ] **Stale Tasks Cleanup**: Identify overdue or completed tasks; archive done items and reschedule remaining priorities.
- [ ] **Memory Consolidation**: Transfer persistent facts, critical decisions, and updated project context from daily notes into `MEMORY.md`.

## Context & File Hygiene
- [ ] **Context Window Check**: Summarize long-running conversations into `memory/` logs to prevent context degradation and maintain high-quality reasoning.
- [ ] **Log Maintenance**: Archive or compress daily notes older than 30 days to keep the file tree structured and lightweight.

## System & Environment Health
- [ ] **Environment Verification**: Check key local tools, database connections, container states, and API keys for uninterrupted background execution.
- [ ] **Self-Correction Audit**: Review recent task failures or error logs from recent sessions to refine future decision-making workflows.
