# Local Infrastructure & Tools

- **Operating System & Shell**:
  - macOS / Linux
  - Core Unix CLI Utilities (`grep`, `sed`, `awk`, `find`, `xargs`, `jq`, `tar`, `rsync`, `tree`)

- **Runtimes & Package Managers**:
  - **Python**: 3.10+ (`pip`, `uv`, `poetry`, `venv`)
  - **Ruby**: Ruby 3.x / Ruby on Rails (`rbenv` / `rvm`, `bundler`, `rake`)
  - **Node.js**: LTS / Current (`npm`, `yarn`, `pnpm`, `nvm`, `bun`)
  - **Rust / Go / C++**: `cargo`, `go`, `gcc` / `clang` (optional local compilation tools)

- **Database Systems & Storage**:
  - **Relational**: PostgreSQL, MySQL, SQLite3
  - **In-Memory / Key-Value**: Redis, Memcached
  - **Database Management CLI**: `psql`, `mysql`, `sqlite3`, `redis-cli`

- **Containerization & Infrastructure**:
  - **Containers**: Docker Engine, Docker Compose, Podman
  - **Cloud & Orchestration CLI**: AWS CLI, Google Cloud SDK (`gcloud`), Azure CLI (`az`), `kubectl`, `helm`, `terraform`

- **Version Control & Repository Tools**:
  - `git`, `gh` (GitHub CLI), `glab` (GitLab CLI)
  - Diff and Merge Utilities (`delta`, `diff`)

- **Networking, Web & API Testing**:
  - `curl`, `wget`, `httpie`
  - Network Diagnostics (`ping`, `traceroute`, `netstat`, `lsof`, `dig`, `nc`)
  - API Inspection (`postman-cli`, `insomnia-cli`)

- **Media & Binary Processing**:
  - **Video / Audio**: `ffmpeg`, `ffprobe`, `yt-dlp`, `imagemagick`
  - **Document & PDF Processing**: `pandoc`, `poppler` (`pdftotext`), `tesseract` (OCR)

- **AI Engine & Code Editors / IDEs**:
  - **LLM / Agent Integration**: OpenAI API, Anthropic API, Local Ollama / vLLM runtime
  - **IDEs & Code Editors**: Cursor IDE, VS Code (Jupyter Extension, Python Kernel), Neovim / Vim
